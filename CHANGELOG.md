# История изменений

## 0.2.9 — 2026-10-15

- Публичные исходники конфигурации, manifest и ссылки на документы по умолчанию настроены на `my.budetoffer.ru`.
- Worker и popup используют `shared/config.ts`; BFF/API URLs следуют выбранному кабинету, сообщение об ошибке подключения берётся из EWANS.
- Локальная упаковка формирует отдельные loopback-разрешения. Тесты проверяют исходную конфигурацию, другой HTTPS-кабинет и локальный режим в настоящих собранных пакетах.

## 0.2.8 — 2026-10-15

- Добавлен общий каталог EWANS для ошибок companion: стабильные коды `BO-COMP-xxx`, объяснения и следующий шаг. Шестиполевой контракт QRKO адаптирован без зависимостей от серверного фреймворка.
- Worker и popup проверяют дескрипторы по локальному каталогу; подменённые сообщения и произвольные внутренние ошибки не выводятся пользователю. Старые ответы поддерживаются.
- Фоновые ошибки сохраняют подтверждённое подключение. HTTP `401` по-прежнему отзывает привязку; HTTP `403` её не удаляет. Метаданные ошибки не заменяют проверки прав и разрешение на действие.
- Сборка включает единый `shared/ewans.js` и переносит только спецификаторы импортов, сохраняя функции, выполняемые Chrome на HH. Добавлены тесты каталога, транспорта, popup и готового архива.

[Как устроен EWANS и где заканчивается его область действия](docs/ewans.md).

## 0.2.7 — 2026-10-15

- Добавлены Prettier 3.9.9, проверки React Hooks и запрет вложенных тернарных выражений по действующим конфигурациям QRKO.
- Проверка TypeScript разделена на браузерный runtime, React popup, Node.js сборку и тесты. Включены проверки неиспользуемых переменных, параметров и fallthrough.
- Все тесты входят в строгую проверку типов и линтер; моки используют узкие Chrome-порты, типизированные задания и проверку данных после сериализации.
- Команды расширения описаны discriminated union, общие guards объединены, обработчики интерфейса разложены на именованные функции.
- Добавлен контроль границ импортов и самостоятельности функций, исполняемых Chrome внутри страниц HH.

Готовые архивы: [GitHub Releases](https://github.com/poizoncc/budetoffer/releases). Обновление установленной из ZIP версии выполняется вручную: [инструкция](docs/install.md#обновите-установленную-версию).

## 0.2.6 — 2026-10-15

- Исходники фонового обработчика, адаптеров HH, контроллера, общих модулей и сборки переведены на TypeScript; интерфейс продолжает использовать TypeScript/TSX.
- Строгая проверка типов охватывает runtime, интерфейс и сборочные скрипты. Внешние JSON-данные, сообщения Chrome и состояние хранилища проверяются перед использованием.
- Сборка компилирует исходные `.ts` в устанавливаемые `.js` и останавливается при ошибках типов. Сериализуемые функции для страниц HH сохраняют самостоятельность.
- Сохранены проверки аккаунта, владельца резюме, срока задания, разрешения на отправку и защиты от повторного выполнения.

## 0.2.5 — 2026-10-15

### Добавлено

- Опубликованы исходники фоновых обработчиков, адаптеров HH и React-интерфейса расширения.
- Самостоятельная сборка из публичных npm-зависимостей и включённых исходников компонентов QRKO; доступ к приватному реестру не нужен.
- Тесты исходников, поиск секретов в файлах, ZIP и Git-истории, сравнение самостоятельной сборки с публикуемым архивом в GitHub Actions.
- Инструкция сборки и отчёт о проверке публикации.

### Изменено

- Генерация CSS ограничена используемыми компонентами расширения. Из-за состава стилей и нового номера версии архив отличается от исторической 0.2.4; фоновые обработчики и проверки HH сохранены.

## 0.2.4 — 2026-10-15

### Исправлено

- Чтение HH больше не останавливается только из-за перенаправления с `hh.ru` на региональный поддомен, если открыта та же страница с теми же параметрами. Принадлежность страницы нужному аккаунту по-прежнему проверяется.
- Вкладки, которые расширение создаёт для чтения HH, защищены от автоматической выгрузки Chrome на время задания. Приостановленная или выгруженная вкладка обрабатывается как остановка задания.

После установки обновления нажмите кнопку обновления BudetOffer на `chrome://extensions`. Ранее остановившуюся проверку резюме запустите ещё раз из кабинета.
