# Сообщить о проблеме безопасности

Не публикуйте в Issues или Pull Requests действующие токены, cookies, коды подключения, данные аккаунтов, содержимое резюме и подробности, позволяющие получить чужой доступ.

Для чувствительного сообщения используйте уже известный вам непубличный канал связи с командой BudetOffer. Если такого канала нет, оставьте [заявку на сайте](https://budetoffer.ru/) с просьбой связаться по вопросу безопасности. В заявке укажите только способ связи и общую тему; согласуйте канал передачи технических деталей отдельно.

В непубличном сообщении полезно указать:

- версию расширения и Chrome;
- затронутую функцию;
- последовательность воспроизведения на собственных тестовых данных;
- ожидаемое и фактическое поведение;
- возможное влияние, без доступа к чужим данным.

Не включайте действующие секреты в доказательство. Если секрет уже раскрыт, прекратите его использование и отзовите соответствующий доступ доступными средствами кабинета или сервиса.

Перед проверкой проблемы обновитесь до [последней опубликованной версии](https://github.com/poizoncc/budetoffer/releases/latest). Для установленного из ZIP расширения обновление выполняется [вручную](docs/install.md#обновите-установленную-версию).
