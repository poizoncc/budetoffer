Версия **0.2.26** добавляет дочитывание длинной переписки и сохраняет результат остальных чатов, если один из них недоступен.

Расширение выбирает чат по свежей подтверждённой записи истории, проверяет аккаунт перед чтением и после него и читает данные выбранной переписки фиксированным GET-запросом. Передаются только разрешённые поля сообщений и участников, без cookies, токенов и заголовков. Неподдержанный формат сопровождается диагностикой структуры. Частичная переписка показывается явно; неизвестный автор не включается в аналитику отказов.

Старые сообщения читаются только по ссылке ресурсов HH или запросу, который делает окно истории при прокрутке. Дубликаты на пересечении страниц объединяются по ID. Если осталась более ранняя история или сработал лимит чтения, это явно показывается в кабинете. Подписи и ссылки кнопок сохраняются как данные; действий от имени пользователя нет.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Проверьте версию **0.2.26**. Обновление поверх установленного расширения сохраняет действующее подключение.

Разрешения Chrome не расширены. Отправка сообщений, заполнение анкет и переходы по внешним контактам не выполняются сборщиком.

`SHA256SUMS` содержит контрольную сумму ZIP. Для установки используйте вложение **budetoffer-chrome.zip**.
