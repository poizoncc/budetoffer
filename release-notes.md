Версия **0.2.19** приводит управление подключением и вход по коду к общим компонентам проекта: Surface, Disclosure и кнопкам UIKit.

Убраны отдельные стили раскрывающихся блоков. Состояние раскрытия доступно для скринридера, управление работает с клавиатуры, поле кода сохраняется при сворачивании.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Проверьте версию **0.2.19**. Не удаляйте установленное расширение: обновление поверх него сохраняет действующее подключение.

Проверены интерфейс расширения, синтетические сценарии HH, типы, линтер и совпадение архива с самостоятельной сборкой. Разрешения Chrome не расширены.

`SHA256SUMS` содержит контрольную сумму ZIP. Для установки используйте вложение **budetoffer-chrome.zip**.
