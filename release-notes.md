Впервые опубликованы исходники Chrome-расширения BudetOffer: фоновые обработчики, адаптеры HH, React-интерфейс и необходимые исходники компонентов QRKO.

**Сборка из исходников:** зависимости загружаются из публичного npm; приватный реестр, аккаунт BudetOffer и секреты не нужны. GitHub Actions проверяет типы, 77 тестов расширения, поиск секретов и побайтное совпадение самостоятельной сборки с архивом релиза.

Фоновые обработчики и проверки HH сохранены. Генерация CSS ограничена компонентами расширения; из-за состава стилей и нового номера версии архив отличается от 0.2.4. Исторический релиз 0.2.4 не заменён.

[Исходники и сборка](https://github.com/poizoncc/budetoffer/blob/v0.2.5/docs/source.md) · [Отчёт о проверке секретов](https://github.com/poizoncc/budetoffer/blob/v0.2.5/docs/security-audit.md)

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Не удаляйте расширение перед обновлением.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
