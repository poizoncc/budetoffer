Версия **0.2.14** добавляет продолжение поиска после первых 20 вакансий.

Расширение сохраняет позицию на HH: номер страницы и смещение внутри неё. По кнопке «Загрузить следующие вакансии» в обновлённом кабинете следующая порция читается с этой позиции. Полные описания передаются отдельно от коротких карточек; аккаунт и адрес проверяются до и после чтения.

- Проверен синтетический сценарий из 45 вакансий на двух страницах HH: 20 + 20 + 5 без повторного чтения первых результатов.
- Ограничения размера порции и срока задания сохранены. Частичная загрузка не выдаётся за полный поиск.
- Разрешения Chrome не расширены; отправка откликов не запускается.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Убедитесь, что установлена версия **0.2.14**. Удалять расширение и заново привязывать аккаунт не нужно.

Старые результаты без позиции продолжения нужно получить новым запуском поиска. После этого кабинет сможет загрузить следующие порции. Реальная проверка пагинации на компьютере пользователя требует обновления установленного расширения.

`SHA256SUMS` содержит контрольную сумму ZIP. Автоматические архивы GitHub **Source code** содержат исходники; для установки используйте вложение **budetoffer-chrome.zip**.
