В этой версии исправлена проверка резюме на региональных адресах HH, включая `kaliningrad.hh.ru`. Переход допускается только для той же страницы с теми же параметрами; проверки аккаунта и владельца резюме сохранены.

Архив включает собранный интерфейс, инструкцию установки и тексты лицензий. Версия рассчитана на Chrome 120 или новее на компьютере и кабинет https://my.budetoffer.ru.

**Обновление установленного расширения:** распакуйте `budetoffer-chrome.zip`, замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Затем повторите проверку резюме в кабинете. Не удаляйте расширение перед обновлением.

Скачивайте вложение **budetoffer-chrome.zip**. Архивы GitHub **Source code** содержат файлы страницы загрузки и не являются распакованным расширением.

`SHA256SUMS` содержит контрольную сумму ZIP; `release.json` — версию и параметры сборки.
