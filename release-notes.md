Версия **0.2.11** исправляет преждевременную остановку чтения HH при загрузке фоновой вкладки.

Chrome может сообщать адрес предыдущей страницы, пока нужное резюме ещё загружается. Расширение теперь дожидается завершения перехода и только затем читает страницу. Это устраняет воспроизведённый случай `unexpected_hh_navigation` при правильном адресе резюме.

- Поддерживаются начальная пустая вкладка и переход между собственными страницами HH, включая региональные поддомены.
- Обнаруженный переход на другой ресурс или адрес с изменёнными параметрами останавливает задание. Расширение не закрывает и не перенаправляет такую вкладку. Загрузка блокирует чтение и управление вкладкой, даже если Chrome скрывает адрес перехода.
- Сохранены проверки аккаунта, владельца резюме и срока задания. Разрешения Chrome не расширены.

Регрессионные проверки используют синтетические данные. Они подтверждают исправление ошибки в исходниках; полный сценарий с реальным аккаунтом HH требует отдельной проверки после обновления установленного расширения.

В чистой папке с Node.js 24.21.0 прошли форматирование, линтер, строгие типы, архитектурные проверки, **128 Node-тестов**, **54 UI-теста**, **15 Python-тестов** и сборка. ZIP побайтно совпал с подготовленным архивом. Gitleaks 8.30.1 не обнаружил секретов в 146 публичных файлах, содержимом ZIP и существующей Git-истории.

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Убедитесь, что указана версия **0.2.11**. Не удаляйте расширение перед обновлением. После обновления запустите остановившуюся проверку ещё раз кнопкой **«Проверить это резюме»** под ссылкой на резюме в кабинете.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
