Версия **0.2.10** устраняет оставшиеся расхождения настроек и устанавливаемого пакета.

- Версия условий для подключения берётся из актуальной конфигурации worker. Сборка и инструкция установки используют минимальную версию Chrome из manifest.
- Чтение истории и результатов откликов согласовано с поддержкой региональных поддоменов HH. Проверки отправки отклика сохраняются.
- Кабинет раздаёт официальный ZIP с проверкой версии, размера и SHA-256. Его сборка больше не может подменить файл другой сборкой с тем же номером.
- Проверены остальные настройки runtime и popup, разрешения, ссылки, режимы, сборочные скрипты и состав ZIP. Документация объясняет, какие loopback-настройки относятся к разработке и Local-упаковке.
- Проверка кандидата и создание релизного тега теперь получают номер из `package.json`; устаревшие команды для 0.2.7 исправлены.

В чистой папке с Node.js 24.21.0 прошли форматирование, линтер, строгие типы, архитектурные проверки, **121 Node-тест**, **54 UI-теста** и сборка. Дополнительно прошли 15 Python-тестов публикации. Результат сборки побайтно совпал с подготовленным ZIP; Gitleaks 8.30.1 не обнаружил секретов в 146 публичных файлах, ZIP и Git-истории.

Проверки используют синтетические данные и не заменяют полный сценарий с реальным аккаунтом HH. Разрешения Chrome не расширены.

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Не удаляйте расширение перед обновлением.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
