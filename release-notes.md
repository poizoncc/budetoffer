В версии **0.2.7** исправлены пробелы предыдущего перехода на TypeScript: правила проверяются для исходников, сборочных скриптов и самих тестов.

- Единый формат Prettier 3.9.9, запрет вложенных тернарных выражений и проверка React Hooks по подтверждённым конфигурациям QRKO.
- Раздельные строгие TypeScript-конфигурации для Chrome runtime, React popup, Node-инструментов и тестов. Моки используют узкие интерфейсы Chrome, а команды — отдельные типы с обязательными полями.
- Автоматический контроль границ импортов, происхождения компонентов QRKO и самостоятельности функций, которые Chrome выполняет внутри страниц HH.

Проверки аккаунта, владельца резюме, сроков заданий и отдельного разрешения на отправку сохранены. Разрешения Chrome не расширены.

**Сборка из исходников:** нужны Node.js 22.19 или новее и публичный npm. CI проверяет формат, линтер, строгие типы, тесты, секреты и побайтное совпадение сборки с архивом релиза.

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Не удаляйте расширение перед обновлением.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
