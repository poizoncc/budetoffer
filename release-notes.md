Версия **0.2.9** согласует опубликованные исходники с конфигурацией расширения для `my.budetoffer.ru`.

- Worker и popup используют `shared/config.ts`. Адреса BFF/API вычисляются из выбранного назначения, а сообщение об ошибке подключения берётся из EWANS.
- Публичные исходники manifest, адресов и ссылок на документы по умолчанию настроены на кабинет BudetOffer.
- Выбор другого HTTPS-кабинета при сборке обновляет всю конфигурацию. Отдельный Local-режим сохраняет loopback-адреса и свои разрешения.
- Тесты проверяют исходную конфигурацию и загружают модули из действительно собранных пакетов для другого кабинета и локального режима.

EWANS внедрён в ошибки companion. Успешные ответы и остальные API продукта сохраняют существующий формат. Полный сценарий с реальным аккаунтом HH не заявляется как проверенный этими тестами. Разрешения Chrome не расширены.

**Проверено:** 118 Node-тестов, 53 UI-теста, 15 тестов проверки релиза, строгие типы, линтер и форматирование.

[Устройство EWANS](https://github.com/poizoncc/budetoffer/blob/v0.2.9/docs/ewans.md) · [Стандарты](https://github.com/poizoncc/budetoffer/blob/v0.2.9/docs/standards.md) · [Самостоятельная сборка](https://github.com/poizoncc/budetoffer/blob/v0.2.9/docs/source.md)

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Не удаляйте расширение перед обновлением.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
