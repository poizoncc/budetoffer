Версия **0.2.8** добавляет EWANS для ошибок подключения Chrome и заданий расширения: понятное объяснение, следующий шаг и стабильный код `BO-COMP-xxx` для поддержки.

- Один каталог на TypeScript используется worker, popup и серверным адаптером. Контракт QRKO адаптирован без NestJS и других серверных зависимостей в расширении.
- Дескрипторы проверяются по локальному каталогу. Подменённые сообщения и произвольные внутренние ошибки не попадают в интерфейс; старые ответы остаются совместимыми.
- Фоновая ошибка не сбрасывает подтверждённое подключение. HTTP `401` по-прежнему отзывает привязку, HTTP `403` её сохраняет. Проверки аккаунта, резюме и отдельного разрешения на отправку остаются обязательными.
- Сборка выпускает единый `shared/ewans.js`. Тесты проверяют контракт, транспорт, popup, импорт модулей и содержимое готового архива.

EWANS внедрён в ошибки companion. Успешные ответы и остальные API продукта сохраняют существующий формат. Полный сценарий с реальным аккаунтом HH не заявляется как проверенный этими тестами. Разрешения Chrome не расширены.

**Проверено:** 116 Node-тестов, 53 UI-теста, 15 тестов проверки релиза, строгие типы, линтер и форматирование.

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Не удаляйте расширение перед обновлением.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
