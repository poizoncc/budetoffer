Версия **0.2.21** исправляет остановку полной истории на пустых списках HH без ID пользователя в данных страницы.

Для строго пустого списка расширение независимо подтверждает текущий аккаунт через свежую главную HH до и после чтения. Пустая страница не используется как доказательство владельца. Для непустых списков сохраняется проверка всех записей; смена аккаунта, неоднозначность и неполная пагинация останавливают чтение. Проверки подтверждения отправки не изменены.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Проверьте версию **0.2.21**. Не удаляйте установленное расширение: обновление поверх него сохраняет действующее подключение.

Проверены интерфейс расширения, синтетические сценарии HH, типы, линтер и совпадение архива с самостоятельной сборкой. Разрешения Chrome не расширены.

`SHA256SUMS` содержит контрольную сумму ZIP. Для установки используйте вложение **budetoffer-chrome.zip**.
