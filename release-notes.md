Версия **0.2.22** исправляет остановку полной истории, когда HH не возвращает пагинацию для пустого списка.

Нулевой общий итог и пустой список записей обрабатываются без обязательной ссылки на следующую страницу. Расширение отдельно подтверждает текущий аккаунт через свежую главную HH до и после чтения. Противоречащие счётчики, включённая следующая страница, смена аккаунта и конфликт владельцев останавливают сбор. Проверки подтверждения отправки не изменены.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Проверьте версию **0.2.22**. Обновление поверх установленного расширения сохраняет действующее подключение.

Добавлен сценарий полного чтения 162 записей на девяти страницах и пустого десятого списка без пагинации, а также проверки противоречивых данных и отсутствующего подтверждения владельца. Разрешения Chrome не расширены.

`SHA256SUMS` содержит контрольную сумму ZIP. Для установки используйте вложение **budetoffer-chrome.zip**.
