Версия **0.2.12** исправляет чтение поиска после перехода с `hh.ru` на региональный поддомен HH.

Исполнитель уже разрешал такой переход с сохранением пути и параметров, но обработчик содержимого поиска повторно сравнивал полный адрес с исходным хостом и останавливался. Теперь он принимает ту же страницу поиска на допустимом региональном HTTPS-домене HH. Путь и строка параметров должны совпадать точно.

- Посторонние домены, учётные данные в URL, нестандартный порт, фрагмент, другой путь и изменённые фильтры по-прежнему отклоняются.
- Проверки аккаунта и срока задания сохранены. Разрешения Chrome не расширены; обновление само не запускает поиск и не отправляет отклики.
- Добавлены четыре регрессионных теста сериализованного обработчика на синтетических страницах.

Это исправление воспроизведённого дефекта исходников. Причина отдельной остановки реального поиска пока не установлена; успешный поиск с реальным аккаунтом HH после обновления не подтверждён.

На Node.js 24.21.0 прошли форматирование, линтер, строгие типы, архитектурные проверки, **132 Node-теста**, **54 UI-теста**, **15 Python-тестов**, сборка и валидатор релиза. ZIP побайтно совпал с подготовленным архивом. Gitleaks 8.30.1 не обнаружил секретов в 147 публичных файлах, содержимом ZIP и существующей Git-истории.

**Установка:** скачайте вложение **budetoffer-chrome.zip**, распакуйте его и загрузите папку в Chrome через `chrome://extensions` → «Загрузить распакованное расширение». Нужен Chrome 120 или новее на компьютере.

**Обновление:** замените файлы в существующей папке BudetOffer и нажмите обновление на `chrome://extensions`. Убедитесь, что указана версия **0.2.12**. Не удаляйте расширение перед обновлением. Затем снова запустите поиск из кабинета: предыдущая остановленная попытка сама не возобновится.

`SHA256SUMS` содержит контрольную сумму ZIP, `release.json` — версию и параметры сборки. Автоматические архивы GitHub **Source code** содержат исходники: для установки в Chrome их сначала нужно собрать.
