Версия **0.2.30** добавляет сбор рекомендаций HH по выбранному резюме без обязательного текстового запроса.

Перед открытием рекомендаций расширение проверяет актуальный аккаунт, владельца резюме и право его редактирования. Проверка повторяется для каждого продолжения сбора. При несовпадении аккаунта или резюме чтение останавливается; повторяющиеся и некорректные идентификаторы отклоняются.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Проверьте версию **0.2.30**. Обновление поверх установленного расширения сохраняет действующее подключение.

Разрешения Chrome не расширены. Сбор рекомендаций не отправляет отклики или сообщения работодателям.

`SHA256SUMS` содержит контрольную сумму ZIP. Для установки используйте вложение **budetoffer-chrome.zip**.
