Версия **0.2.20** исправляет чтение идентификаторов владельца на страницах истории HH: поддерживаются числа и канонические числовые строки.

Проверка совпадения владельца всех записей сохранена. Неоднозначные, чужие и пустые списки без доказательства владельца не считаются подтверждённой историей. При остановке расширение передаёт безопасную причину отказа для кабинета.

**Обновление:** замените файлы в существующей папке BudetOffer содержимым `budetoffer-chrome.zip`, затем нажмите обновление расширения на `chrome://extensions`. Проверьте версию **0.2.20**. Не удаляйте установленное расширение: обновление поверх него сохраняет действующее подключение.

Проверены интерфейс расширения, синтетические сценарии HH, типы, линтер и совпадение архива с самостоятельной сборкой. Разрешения Chrome не расширены.

`SHA256SUMS` содержит контрольную сумму ZIP. Для установки используйте вложение **budetoffer-chrome.zip**.
