# Опубликуйте версию расширения

Инструкция для команды BudetOffer. Пользователям готовый ZIP доступен в [Releases](https://github.com/poizoncc/budetoffer/releases).

## Подготовьте архив

1. В рабочем репозитории продукта обновите версию в `apps/chrome-companion/manifest.json` и проверьте изменения расширения. Номер версии должен быть новым; уже опубликованные версии не заменяются.
2. Из корня рабочего репозитория выполните:

   ```bash
   npm run chairs:companion:release:prepare -- /absolute/path/to/budetoffer/distribution
   ```

   Здесь `/absolute/path/to/budetoffer` — ваш отдельный checkout публичного репозитория `poizoncc/budetoffer`. Команда собирает только разрешённые файлы расширения, интерфейс и лицензии, затем создаёт:

   - `distribution/budetoffer-chrome.zip` — устанавливаемое расширение;
   - `distribution/SHA256SUMS` — SHA-256 архива;
   - `distribution/release.json` — версия, размер, контрольная сумма и адрес кабинета.

3. В публичном репозитории обновите `CHANGELOG.md` и `release-notes.md`. В заметках укажите изменения и действия пользователя при обновлении.
4. Запустите проверку, подставив новую версию:

   ```bash
   python3 scripts/validate-release.py --tag v0.2.4
   ```

   Проверка сверяет версию внутри ZIP, его контрольную сумму, состав файлов и разрешения Chrome. Она не обращается к аккаунтам или резюме HH.

## Опубликуйте проверенную версию

1. Сохраните документы и каталог `distribution` коммитом в `main` публичного репозитория, затем отправьте коммит в GitHub.
2. Создайте и отправьте тег той же версии:

   ```bash
   git tag -a v0.2.4 -m "BudetOffer Chrome 0.2.4"
   git push origin v0.2.4
   ```

3. Дождитесь успешного workflow **Extension** во вкладке [Actions](https://github.com/poizoncc/budetoffer/actions).

Workflow проверяет файлы из коммита тега, загружает три файла в черновик релиза и публикует его только после проверки вложений. Для публикации используется встроенный токен GitHub Actions с правом записи в содержимое этого репозитория. Личный токен в файлах или secrets не нужен.

Готовый ZIP доступен по постоянной ссылке:

<https://github.com/poizoncc/budetoffer/releases/latest/download/budetoffer-chrome.zip>

## Если публикация остановилась

Откройте журнал workflow. При несовпадении версии, контрольной суммы или разрешений исправьте пакет до создания нового релиза. Опубликованные вложения и теги не перезаписывайте.

Если остался черновик после сбоя загрузки, сначала проверьте его состояние и уже загруженные файлы через GitHub CLI. Workflow намеренно отказывается заменять существующий релиз; после проверки можно удалить только незавершённый черновик и повторить запуск. Если релиз уже опубликован, исправление выпускается под новым номером версии.

Автоматического обновления распакованной установки в Chrome нет: пользователи заменяют файлы в существующей папке и обновляют расширение на `chrome://extensions`.
