# Как помочь BudetOffer

Этот репозиторий содержит готовые версии расширения Chrome, инструкции и публичные обращения пользователей.

## Сообщить об ошибке

1. Проверьте [решение проблем](docs/troubleshooting.md) и [последний релиз](https://github.com/poizoncc/budetoffer/releases/latest).
2. Посмотрите [открытые Issues](https://github.com/poizoncc/budetoffer/issues), чтобы не создавать дубликат.
3. Создайте обращение по форме **«Ошибка»**. Укажите версию расширения и Chrome, шаги, ожидаемый результат и фактическую ошибку.

Публикуйте только данные, нужные для воспроизведения. На скриншотах скройте личные контакты и содержимое резюме. Не прикладывайте коды входа, пароли, cookies, токены или данные хранилища расширения.

## Предложить улучшение

Используйте форму **«Предложение»** в Issues. Опишите задачу, текущую трудность и результат, который хотите получить. Пример сценария полезнее списка интерфейсных пожеланий.

## Исправить документацию

Отправьте Pull Request с небольшим, самостоятельным изменением. Укажите, какое место было непонятным, и сверьте названия кнопок с актуальной версией расширения или кабинета. Не добавляйте реальные резюме и личные данные даже в примеры.

Вопросы уязвимостей рассматриваются отдельно: [как безопасно сообщить о проблеме](SECURITY.md).
