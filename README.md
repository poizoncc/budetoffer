# BudetOffer — расширение для Chrome

Расширение связывает [кабинет BudetOffer](https://my.budetoffer.ru/) с вашим аккаунтом HH в Chrome на компьютере. Оно выполняет задания из кабинета: проверяет выбранное резюме, читает данные для импорта профиля и получает доступные результаты откликов.

В этом репозитории публикуются исходники расширения, самостоятельная сборка, готовые версии и инструкции по установке. О сервисе: [budetoffer.ru](https://budetoffer.ru/).

## Скачать и установить

**[Скачать последнюю версию — budetoffer-chrome.zip](https://my.budetoffer.ru/downloads/budetoffer-chrome.zip)** · [Все версии и изменения](https://github.com/poizoncc/budetoffer/releases)

Версия 0.2.34 раскрывает историю работы на странице HH перед чтением. Это исправляет импорт только трёх последних мест, когда остальные записи скрыты за кнопкой раскрытия. Читаются опыт, образование, языки и остальные заполненные поля. Перед сохранением проверьте текст в кабинете; отсутствующие сведения не дописываются по догадке.

Начиная с 0.2.32 в разделе «Профиль» кабинета можно запустить чтение всех резюме текущего аккаунта HH. После чтения выберите нужный текст и проверьте его перед сохранением в BudetOffer. Непрочитанные резюме отображаются отдельно.

Если расширение установлено [из Chrome Web Store](https://chromewebstore.google.com/detail/budetoffer-server-compani/anipjflngjmjmekchemjbhgcpedjibbc), обновление приходит через магазин после публикации новой версии. Инструкция с ZIP ниже относится к установке в режиме разработчика.

Выбирайте вложение **budetoffer-chrome.zip** в релизе. Автоматические архивы GitHub **Source code** содержат этот репозиторий и не устанавливаются как расширение.

Нужен **Google Chrome 120 или новее на компьютере**, аккаунт BudetOffer и вход в HH в том же браузере. На телефоне можно пользоваться кабинетом и подтверждать подключение, а расширение устанавливается на компьютер.

1. Распакуйте архив и сохраните папку `budetoffer-chrome` в постоянном месте.
2. Откройте в Chrome `chrome://extensions` и включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `budetoffer-chrome`, внутри которой находится `manifest.json`.
4. Откройте кабинет в этом же Chrome, перейдите в **«Профиль и настройки → Подключения»** и нажмите **«Подключить расширение»**. Код вручную вводить не нужно. В окне расширения подтвердите обязательные условия. Для кабинета на телефоне остаётся способ через код из расширения.
5. Войдите в HH в этом Chrome. В [разделе «Резюме HH»](https://my.budetoffer.ru/profile?view=resume#base-resume) нажмите **«Прочитать все резюме из HH»**, затем выберите резюме кнопкой **«Проверить текст»**. Для чтения одного резюме откройте **«По ссылке»** и нажмите **«Импортировать резюме из HH»**.

После обновления расширения заново прочитайте резюме: прежний результат содержит только уже полученные записи. Перед сохранением проверьте наличие ранних мест работы. Вход в расширение и сохранение резюме — отдельные шаги.

## Исходники и самостоятельная сборка

Можно прочитать [фоновую обработку заданий](apps/chrome-companion/background), [код работы со страницами HH](apps/chrome-companion/hh), [интерфейс расширения](apps/ui-layer/src/pages/companion-popup) и [сборку пакета](scripts/package-companion.ts). Исходный код расширения и сборки написан на TypeScript; React-интерфейс использует TSX. В устанавливаемом пакете остаётся обычный JavaScript, который выполняет Chrome.

Для сборки нужны Node.js 22.19 или новее и npm; в CI используется Node.js 24. Из корня этого репозитория:

```bash
npm ci --ignore-scripts --registry=https://registry.npmjs.org
npm run format:check
npm run lint
npm run check
npm test
npm run build
```

Готовая папка для загрузки через `chrome://extensions` — `build/budetoffer-chrome`, архив — `build/budetoffer-chrome.zip`. Для сборки не нужны аккаунт, токен, закрытые npm-пакеты или исходники сервера BudetOffer. Prettier проверяет формат; ESLint с neostandard и React Hooks — корректность, зависимости effects и запрет `any` и подавлений. `npm run check` проверяет строгие типы runtime, интерфейса, сборочных скриптов, **Node- и UI-тестов**, затем границы импортов и происхождение vendored-файлов.

## Обновление

Для установленной из ZIP версии обновления применяются вручную:

1. Скачайте свежий архив из [Releases](https://github.com/poizoncc/budetoffer/releases).
2. Распакуйте его и замените содержимое **той папки, из которой уже установлено расширение**.
3. В `chrome://extensions` нажмите кнопку обновления на карточке BudetOffer и проверьте номер версии.

Сохраните расположение папки и не удаляйте расширение перед обновлением. Загрузка новой отдельной копии может потребовать повторного подключения к кабинету.

## Как работает связь с HH

Действия запускаются из кабинета и выполняются через Chrome, в котором вы вошли в HH. Пока идёт задание, компьютер должен быть включён, а Chrome — открыт. Окно расширения и вкладку HH можно свернуть. Сон компьютера и закрытие браузера приостанавливают работу.

Подключение расширения само по себе не отправляет отклики. Доступность конкретных действий и результат каждого задания проверяйте в кабинете.

В исходниках также есть исполнитель отправки отклика: он проверяет аккаунт, выбранное резюме и историю, затем запрашивает отдельное разрешение сервера перед отправкой. Наличие этого кода не включает отправку автоматически. [Подробнее о потоке данных и проверках](docs/source.md#как-проходят-задания-и-данные).

## Разрешения

Публичная сборка запрашивает доступ к `my.budetoffer.ru`, `hh.ru` и региональным поддоменам HH. Разрешения Chrome используются для следующих задач:

| Разрешение  | Для чего нужно                                                             |
| ----------- | -------------------------------------------------------------------------- |
| `activeTab` | Работа с выбранной вкладкой HH при доступных действиях расширения.         |
| `scripting` | Проверка аккаунта и чтение поддерживаемых страниц HH для заданий кабинета. |
| `storage`   | Сохранение подключения и состояния расширения между открытиями.            |
| `alarms`    | Проверка новых заданий и состояния подключения, пока Chrome открыт.        |

Пароль HH в расширение вводить не нужно: войдите на самом сайте HH. [Условия использования](https://my.budetoffer.ru/legal/terms) · [Политика конфиденциальности](https://my.budetoffer.ru/legal/privacy)
